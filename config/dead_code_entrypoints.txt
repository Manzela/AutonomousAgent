# dead_code_entrypoints.txt — Operator-approved escape hatch for dead-code-gate (C4)
#
# PURPOSE:
#   Symbols listed here are treated as runtime entrypoints by dead_code_gate.py,
#   even if no `if __name__ == "__main__":` block or pyproject [project.scripts]
#   entry is present. This allows operator-reviewed modules that are invoked by
#   external harnesses, Docker CMD, service meshes, or other runtime contexts
#   not visible to static analysis.
#
# RULES (ENFORCED):
#   1. Entries MUST be added by an operator in a SEPARATE commit from the code
#      being exempted (4-eyes principle — same as audit rubric changes).
#   2. Self-waivers (@manual, # dead-code: ignore, # noqa: deadcode) are
#      FORBIDDEN in the diff itself. This file is the ONLY allowed exemption path.
#   3. Each entry must include a comment explaining WHY it is an entrypoint.
#   4. Entries are one of:
#        module.dotted.path          — treats the whole module as an entrypoint root
#        module.dotted.path:symbol   — treats a specific symbol as a root
#
# FORMAT: one entry per line; '#' lines are comments; blank lines ignored.
#
# ---------------------------------------------------------------------------
