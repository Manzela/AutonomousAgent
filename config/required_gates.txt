# required_gates.txt — curated allowlist of check-run names that MUST be
# required status checks on main.
#
# Inclusion criteria:
#   1. The check-run is safety/integrity-bearing (not just style/advisory).
#   2. Its workflow triggers on EVERY pull_request with NO paths:/paths-ignore:
#      filter and NO continue-on-error at the JOB level, so it always emits a
#      result and never hangs a PR in "pending" forever.
#
# Format: one check-run name per line; blank lines and lines starting with '#'
# are ignored by scripts/ci/check_required_gates_coverage.py.
#
# OPERATOR ACTION REQUIRED: changes here take effect only after an operator
# runs `terraform apply` (terraform/phase-0a-gcp/branch_protection.tf) OR:
#   gh api repos/Manzela/AutonomousAgent/branches/main/protection \
#     -X PATCH --input /dev/stdin <<'JSON'
#   {"required_status_checks":{"strict":true,"contexts":[<names>]}}
#   JSON
# HIGH-STAKES: a required gate that does not run on a given PR stays "pending"
# forever and BLOCKS that merge.  Every gate below has been verified UNCONDITIONAL.
